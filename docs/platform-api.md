# Platform API

What the storefront talks to. Base URL `http://localhost:4000`.

## `GET /v1/games`

```json
{
  "games": [
    { "gameId": "nova-arena", "displayName": "Nova Arena", "live": true },
    { "gameId": "drift-club", "displayName": "Drift Club", "live": false }
  ]
}
```

`live` is whether the integration is enabled for players.

## `GET /v1/games/{gameId}/offers?playerId={playerId}`

Offers for that player, normalised across games.

```json
{
  "gameId": "nova-arena",
  "offers": [
    {
      "gameId": "nova-arena",
      "offerId": "gems_small",
      "gameItemId": "gems_small",
      "name": "Small Gem Pack",
      "priceMinor": 499,
      "currency": "EUR"
    }
  ]
}
```

`offerId` is the platform's identifier. `gameItemId` is what the game calls it.

## `POST /v1/orders`

```json
{
  "gameId": "nova-arena",
  "playerId": "p-1001",
  "offerId": "gems_small",
  "idempotencyKey": "<caller-generated>"
}
```

Creates the order and delivers it. Responds `201` with the order.

`idempotencyKey` is generated by the caller. Repeating a request with the same
key returns the original order rather than creating a second one.

Header `X-Platform-Preview: true` permits orders against a game where
`live` is false.

Errors: `403 game_not_live`, `404 unknown_game`, `404 offer_not_found`,
`400 missing_field`.

## `GET /v1/orders/{orderId}`

```json
{
  "orderId": "ord_a1b2c3d4e5f6",
  "gameId": "nova-arena",
  "playerId": "p-1001",
  "offerId": "gems_small",
  "priceMinor": 499,
  "currency": "EUR",
  "status": "delivered",
  "grantId": "0b3f...",
  "failureReason": null,
  "createdAt": "2026-02-11T09:14:22Z",
  "updatedAt": "2026-02-11T09:14:22Z"
}
```

`status` is one of `pending`, `delivered`, `failed`, `refunded`.

## `GET /v1/players/{playerId}/orders`

That player's orders, newest first.

## `GET /v1/games/{gameId}/players/{playerId}/inventory`

What the game says the player owns, passed straight through. The platform does
not normalise this; `body` is whatever the game returned, and `status` is the
status it returned.

```json
{
  "gameId": "nova-arena",
  "status": 200,
  "body": { "playerId": "p-1001", "items": [ { "itemId": "gems_small", "quantity": 1 } ] }
}
```

## `POST /v1/orders/{orderId}/refund`

Refunds the order and asks the game to revoke the grant.
